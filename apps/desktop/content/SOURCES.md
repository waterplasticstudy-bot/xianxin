# 课程与视频来源

站内讲解和习题为本项目原创。视频为外部学习参考，不下载、不转载视频或整套字幕。核对日期：2026-11-15；公开视频索引/官方资料核实，不代表已逐集验证播放。

- Keysking：[B站绪论与合集入口](https://www.bilibili.com/video/BV12v4y1y7uV/)、[作者文档](https://docs.baud-dance.com/docs/stm32/intro/)。课程采用F103/HAL，和本机F446工程分别标注。
- GPIO：[Keysking GPIO内部原理](https://www.bilibili.com/video/BV1zG4y1K78S/)。
- PWM：[Keysking PWM](https://www.bilibili.com/video/BV1Yx4y1x7xY/)。
- C：[鱼C-小甲鱼](https://www.bilibili.com/video/BV17s411N78s/)。
- 指针：[江协科技](https://www.bilibili.com/video/BV1Mb4y1X7dz/)。
- HAL补充：[正点原子](https://www.bilibili.com/video/BV1bv4y1R7dp/)、[F407官方资料互链](https://www.openedv.com/thread-340198-1-1.html)。跨系列内容，不是F446专用。
- SPL原理参考：[江协STM32](https://www.bilibili.com/video/BV1th411z7sn/)、[作者官网](https://jiangxiekeji.com/tutorial/32.html)。SPL同样是库，不是寄存器直写。
- C++：[黑马程序员](https://www.bilibili.com/video/BV1et411b73Z/)。后续桌面C++参考，不作为STM32前置条件。
- 工具版本：[ST官方CubeIDE 2.0说明](https://community.st.com/stm32cubeide-mcus-28/stm32cubeide-2-0-0-released-159542)，确认CubeMX与CubeIDE分开安装。
- API：[DeepSeek官方文档](https://api-docs.deepseek.com/)及[模型列表](https://api-docs.deepseek.com/api/list-models/)。模型由设置选择，实际可用性按账户接口返回。

本版21节可学课、35题：14节C各含1道概念题和1道实际编译题；6节STM32无板原理课和1节C++衔接课各含1道概念题。另两项后续路线未开放，不计入可学习进度。STM32代码示意不是PC上的C11完整程序；课程测验不等于硬件验证。
