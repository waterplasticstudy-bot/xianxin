闲芯 · 慢慢学，认真懂 / 桌面前端说明

文件：index.html、style.css、app.js、xianxin-icon.png。原生 HTML/CSS/JavaScript，无构建步骤、外部字体或 CDN。
由本地 Python 服务根路径提供；不要直接以 file:// 打开 index.html。

路由：#today、#courses、#lesson/<id>、#practice、#review、#report、#ask、#settings。
练习可用 #practice?exercise=<id> 定位。课程与练习全部读取 /api/bootstrap。
课程页的“专注练习”打开独立练习区；“返回阅读位置”恢复本课阅读锚点与偏移。
位置按课程存于当前标签页的 sessionStorage，页面重载仍保留；不写入学习备份。
理解题未选择答案时不能提交，选项区域和操作按钮均提供至少 44 px 点击热区。

数据：草稿与笔记防抖保存到后端。练习结果、助学标记、学习时间、日报与对话依赖真实 API 状态。
错误选择不会直接展开参考解析；提示与解析先写入 /api/hint，才显示内容。
正在编译的代码编辑器只读；参考/AI 代码永不自动执行。
导出前保存未同步草稿、笔记与计时。导入预览需二次确认，并等待旧保存完成。

计时：主动点击开始；每秒按单调时钟计算，30 秒提交幂等片段。
页面隐藏、2 分钟无交互或检测到休眠均暂停。切换到另一课程时暂停。
Web Locks 排他锁防止同源多标签页重复计时；旧浏览器使用 localStorage 短租约。
待同步片段写入 localStorage，入队时捕获 occurredAt ISO 时间；重试保留原时间，服务器按 Asia/Taipei 归属日期。
页面不会自动恢复计时。选择课程、打开页面或滚动本身均不会开始计时。

AI：无密钥/关闭/未选模型时明确引导设置，不提供假离线回答。
模型读取实际 /api/models；填写新密钥后点击读取会先保存密钥，字段随即清空。
课程目标、正文、要点、题目与起始代码可展开查看；代码草稿需单独勾选才发送。
同课最近 8 条对话由后端附带。聊天请求不会携带私人笔记。

重置：设置页二次确认后暂停计时，锁住当前界面并等待已发出的写请求。
先同步草稿、笔记、未保存日报与计时；全部成功后调用 POST /api/reset {confirmation:"RESET"}。
服务返回 state 且 backupCreated 为 true 后，才清空本标签页的反馈、选择、草稿、阅读位置和计时缓存。
同步或重置失败时保留数据；计时保持暂停。后台对话/编译/模型读取期间不可重置。
AI 关闭与自动备份由后端保证，浏览器不读取 API 密钥；手机生产代码和数据不参与重置。

视觉：240 px 桌面侧栏、温暖浅灰底、白色卡片、石墨文字与单蓝强调。
图标沿用手机闲芯品牌；芯片 SVG 无外部资源。CSS 采用单份组件规则和四个响应式断点，
不再保留旧版多轮字号覆盖。正文桌面 16 px、手机 15 px，输入一般 16 px，操作按钮 >=44 px。
支持键盘焦点、屏幕阅读器标签与 reduced-motion。窄屏导航支持 Tab 循环与 Esc 关闭。聊天 Enter 发送/Shift+Enter 换行，代码 Tab 插入空格。
